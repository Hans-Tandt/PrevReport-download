# PrevReport — download

Windows desktop app for prevention advisers. It asks the questions of the periodic and annual
safety report of a division, saves the answers, and writes the Word report in the division's
language.

- **Countries:** Belgium (SIPPT monthly / quarterly report, annual report form A), France, Germany.
- **Screens and questions:** English, French, Dutch, German.
- **Offline:** no internet needed; your data stays on your PC.
- **Free to use.**

The rules in the app come from the official Belgian FPS forms and notice, and from the laws of
France and Germany listed in the manual. The app helps you write the report; it is not legal advice.

## Download and start

1. Open **[Releases](../../releases)** and download `PrevReport_V1.4.zip`.
2. Unzip it in a folder where you can write (Desktop or Documents — not `C:\Program Files`).
3. Double-click `PrevReport.exe`. Nothing else to install.

On the first start the app uses the demo data in `Test_Folder` (fictitious companies), so you can
try everything at once. For real work: ⚙ Settings → Folders. The user manual (EN / FR / NL / DE)
opens with the **INFO** button.

Windows may warn that the app is from an unknown publisher (it is not signed): click
**More info → Run anyway**.
